# 公開するファイル

このリポジトリは、ソースコード、使用方法、録音の保護を実行するための固定モデルを公開します。学習済み重みの公開を含みますが、個別の実験のレポート・評価結果・ログは公開対象にしません。

## 収録するもの

- 日本語画面、コマンドライン、保護処理、モデル構造。
- 前処理、GE2E の追加学習、検証、モデル登録のコード。
- セットアップと起動のスクリプト。
- 日本語の使用説明、データの利用条件への案内、第三者の許諾文。
- 合成した試験用データをその場で作る確認コード。
- `models/encoder.pt` と `models/encoder_ja.pt`、および `models/registry.json`。

## 収録しないもの

- 上記 2 ファイル以外の追加の重み、日本語モデルの学習再開用チェックポイントと最適化状態。
- 学習・評価の数値、結果レポート、実験ログ。
- データセット、取得済み ZIP、中間特徴量。
- 元の録音、保護した音声、クローンなどの生成音声。
- 実行環境のパス、個人用設定、認証情報。
- 既存の学習結果やローカル音声に依存する検証用ファイル。

生成物は `.gitignore` で除外しています。後から自分で学習した場合も、公開前に `git diff --cached --name-only` で対象を確認してください。すでに追跡しているファイルには、後から追加した除外規則だけでは反映されません。
