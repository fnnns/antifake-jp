# 日本語の学習データについて

本リポジトリの前処理は、JVS 形式 ZIP の `jvsNNN/parallel100/` と `jvsNNN/nonpara30/` にある通常の読み上げ WAV を対象とします。ささやき声と裏声は対象にしません。

## 取得元と利用条件

[JVS 作成者の公開ページ](https://sites.google.com/site/shinnosuketakamichi/research-topics/jvs_corpus) で、データと利用条件を確認してください。音声は、学術機関の研究、非商用研究、個人利用について条件が示されています。コーパス全体の再配布は認められていません。タグは CC BY-SA 4.0、テキストは元の JSUT の条件です。GE2E の学習入力に文字起こしは使用しません。

`training/download_data.py` は、固定した独立公開アーカイブを取得し、サイズと SHA-256 を確認します。これは作成者による推薦・承認を意味しません。取得先のリポジトリ全体に付いた表示で、元の JVS の利用条件を置き換えないでください。自分で取得した ZIP を `--archive` で指定することもできます。

録音・特徴量・取得済み ZIP は GitHub へ収録しません。

## 前処理

- 16 kHz・モノラルへ変換します。
- エネルギーに基づいて長い無音を取り除き、必要な前後の余白を残します。
- 小さい音声だけを基準音量まで増幅します。
- 40 次元の Slaney Mel 特徴量を保存します。
- 有効な長さが足りない音声は、除外理由をローカルの記録へ保存します。
- 話者単位で学習・検証・テストへ固定分割します。性別タグを読み込めた場合は層別化します。

同じ話者や同一の録音が複数の集合へ入らないように確認し、学習開始前に特徴量の検証値も確認します。実験結果を見て同じテスト集合に合わせた調整を繰り返した場合、その集合を未使用の独立テストとして扱えません。
