# 日本語話者エンコーダーの追加学習

このフォルダーは、JVS 形式の通常読み上げ音声で RTVC 話者エンコーダーを追加学習するためのコードです。録音の保護だけなら、`models/` に同梱した日本語モデルを利用でき、追加学習は不要です。過去の学習・評価レポート、スコア、ログは含めません。

## 基本の流れ

1. 元の RTVC モデルを取得します。
2. 使用条件を確認した JVS 形式 ZIP を用意します。
3. ZIP から特徴量と、話者単位の学習・検証・テスト分割を作ります。
4. 元の重みを初期値にして、新しい Adam で GE2E の追加学習を行います。
5. 検証集合だけで候補を選び、最後に別のテスト集合で評価します。
6. 推論用のモデルを新しいファイルへ保存し、アプリに登録します。

文字起こしは入力に使いません。同じ話者の複数の発話をまとめて学習するため、正しい話者 ID が必要です。

## 自動で実行する

GPU 版のセットアップ後、ルートの `学習を実行.cmd` を実行します。データがなければ取得し、前処理、追加学習、検証、登録を順に行います。取得元と利用条件は [データについて](../docs/DATA.md) にあります。

元のモデルは上書きせず、新しい日時の実行先を使います。初期値は学習率 `1e-5`、8 人 × 各 5 発話、上限 3,000 回です。これらは実行用の初期設定で、特定の精度や防御性能を保証する値ではありません。

## 手動で実行する

ルートから実行する例です。

```powershell
.\.venv\Scripts\python.exe training/pipeline.py preprocess --archive "C:\datasets\jvs_ver1.zip" --out training/data
.\.venv\Scripts\python.exe training/pipeline.py train --data training/data --pretrained models/encoder.pt --run-dir training/runs/my_run --steps 3000 --eval-every 500 --patience 3 --min-steps 1000 --speakers 8 --utterances 5 --lr 0.00001 --device cuda
.\.venv\Scripts\python.exe training/register_model.py --run-dir training/runs/my_run --output-name encoder_ja_custom.pt
```

登録後は、画面の「日本語で微調整したモデル」で選べます。`--activate` を登録コマンドに追加すると、自動選択もそのモデルになります。

## 実装

入力は 40 次元の Mel 特徴量で、学習時は 160 フレームをランダムに切り出します。同一話者の比較では、照合中の発話自身を除いた重心を使います。初期のモデル重みだけを読み込み、以前の最適化状態と反復回数は引き継ぎません。

検証の EER を基準に選び、同点の場合は同一話者と異話者の余弦類似度の分離幅を使います。学習済みの候補と、比較用の元モデルを分けて扱います。テスト集合は選択が終わってから評価します。

重み、設定、結果、スコア、発話の対応、ログは指定したローカルの実行先へ作成されます。これらの生成物は `.gitignore` による公開除外の対象です。

話者認証の性能改善と、他の音声クローンモデルへの防御効果は別です。防御について主張するには、独立したクローン生成の対照実験と聴取評価が必要です。
